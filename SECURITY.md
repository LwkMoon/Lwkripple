# Security Policy

If you find a security problem in lwkripple, please report it privately through
[GitHub Security Advisories](https://github.com/LwkMoon/lwkripple/security/advisories/new)
instead of opening a public issue. You will get a reply as soon as possible.

lwkripple has no runtime dependencies and makes no network requests of its own
(it only loads an image when you pass one to the `image` option).
